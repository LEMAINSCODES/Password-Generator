# Secure Password Generator

A lightweight Python command-line tool that generates strong, randomized passwords based on user-defined lengths and character constraints.

## 🔒 Features
- Customizable password length (with built-in minimum security warning).
- Optional inclusion of numbers (`0-9`).
- Optional inclusion of special characters (`!@#$%^&*`).
- Built entirely using standard Python modules (`random`, `string`).
